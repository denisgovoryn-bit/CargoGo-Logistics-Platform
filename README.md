# CargoGo Prague

MVP сервиса грузоперевозок в Праге.

## Workspace

- `apps/mobile` — мобильное приложение React Native с Expo Router.
- `apps/admin` — административная панель Next.js.
- `docs` — документация проекта.

## Требования

- Node.js 22
- npm

## Команды

```bash
npm run mobile
npm run admin
npm run lint
npm run typecheck
```
